# سجل التحقق — ٣١ أغسطس ٢٠٢٦

## النطاق والنتيجة

نسخة توضيحية كاملة لشركة افتراضية: ٢٣ صفحة محتوى، سبع خدمات، ست دراسات أعمال، ونموذجا استفسار محليان. لا يوجد خادم لاستقبال الطلبات أو رفع الملفات أو دفع إلكتروني. بيانات التواصل والأعمال والشهادات افتراضية ومعلّمة بذلك.

## التحقق المنفّذ

- نجح بناء الإنتاج، فحص TypeScript، وفحص lint.
- فحص جميع الاعتماديات عبر npm audit: صفر ثغرات معروفة وقت الاختبار، وليس ضمانًا أمنيًا دائمًا.
- زحف إلى ٢٣ صفحة: حالة 200، عنوان ووصف ووسوم مشاركة ورابط أساسي، عنوان H1 واحد، لغة عربية واتجاه RTL، وصحة روابط الصفحات والمراسي وملفات الصور المحلية.
- ثلاثة مسارات مجهولة، عامة وضمن الخدمات والأعمال، أعادت 404 المخصصة.
- نجح الزحف نفسه إلى النسخة المنشورة عبر وصول المالك المصرّح به. وصول الزائر العام يعرض تسجيل الدخول، لأن النشر خاص بالحساب.
- اجتازت ثمانية اختبارات للتحقق من الطلب: الأرقام العربية والعراقية الدولية، رفض الهاتف غير الصحيح، الحقول المطلوبة، البريد الشرطي، الكمية الصحيحة، والتواريخ الماضية والمستقبلية.
- المتصفح: قائمة الهاتف وفتحها وإغلاقها والتنقل منها، تصفية الأعمال، فتح المشروع وتكبير صورته وإغلاقها، وتمرير الخدمة المختارة إلى نموذج العرض.
- النموذج: أخطاء عربية، أرقام عربية، كمية سالبة مرفوضة، بريد مطلوب عند اختياره، ملف غير مدعوم مرفوض، صورة WebP مقبولة محليًا، حالة نجاح صادقة، نسخ الملخص، وتعديل البيانات مع بقائها.
- نموذج التواصل أنشأ ملخص استفسار محليًا بنجاح. زر النسخ أكد نجاح النسخ.
- إعدادات الخصوصية: الرفض الاختياري، فتح الإعدادات، تغيير التفضيلات، الحفظ وإعادة الفتح للتحقق من استمرارها.
- روابط الاتصال الافتراضية عرضت تنبيهًا بدل الاتصال بجهة غير موثقة. رابط الخريطة يعرّف نفسه كرابط خارجي عام للمنطقة.
- الأسئلة الشائعة تفتح إجاباتها وتحمل حالة expanded الصحيحة.
- عولج اختلاف معرّفات الأسئلة بين عرض الخادم والمتصفح بإعطاء معرّفات ثابتة؛ تأكد ربط السؤال بالإجابة ولم تتكرر رسالة عدم التطابق في إعادة الاختبار.
- فحص لقطات واجهات فعلية عند 390 و1440 بكسل. فحوص عرض DOM إضافية عند 768 و1920 بكسل لم تظهر تجاوزًا أفقيًا في الصفحات المفحوصة.
- أُصلحت نافذة الخصوصية على الهاتف إلى نص 12 بكسل وأزرار بارتفاع 44 بكسل. أكدت لقطة محدثة وضوح النص وبقاء زر الطلب ظاهرًا. المراجع المستقل أعطى نتيجة ship للملاحظتين المحددتين بعد الإصلاح، وليس اعتمادًا شاملًا لكل سلوك محتمل.

## حدود الأدلة

لم يُنفّذ تدقيق وصول شامل بقارئ شاشة، أو اختبار لجميع الأجهزة والمتصفحات، أو قياس Lighthouse/Core Web Vitals ميداني. الصور والخطوط محلية ومضغوطة؛ لا يُدّعى رقم أداء غير مقاس.

طلب تنزيل الملخص يولد ملفًا نصيًا محليًا ويعرض بديل النسخ والمراجعة. لم يرصد متصفح Codex ملف تنزيل مكتملًا أثناء الاختبار؛ النسخ ومحتوى الملخص المرئي تحققا فعليًا. لذلك لا يُعرض نجاح تنزيل مؤكد للمستخدم.

فحص الواجهة المستقل يستخدم لقطات viewport محددة مع قراءة المصدر. لقطات الصفحة الطويلة المشوّهة من أداة التصوير حُذفت ولم تُستخدم كدليل. نتيجة اختيار الاتجاه الأصلية لم يُحفظ مفتاحها المؤقت؛ وثيقة التصميم تسجل الاتجاه والقرار دون اختلاق مفتاح.

## قبل استخدام تجاري حقيقي

استبدال بيانات الشركة، توثيق الحقوق وبيانات الأعمال، مراجعة النصوص القانونية بحسب التشغيل الفعلي، وربط النماذج باستقبال آمن مع سياسة احتفاظ ومكافحة إساءة استخدام والتحقق من الملفات على الخادم. لا يكفي تغيير رسالة النجاح لتفعيل الاستقبال.
